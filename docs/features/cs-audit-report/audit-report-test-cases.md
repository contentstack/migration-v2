## Gaps / Needs Clarification

- Resolved 2026-08-05 and now covered by cases rather than listed as gaps: the FR-2.2/FR-2.3 conflict (FR-2.3 was inverted and has been corrected), the write-timing contradiction between UC-2 and AC-6.4 (resolved to a single write on Continue, FR-7.5), and whether a category toggle clears its per-item overrides (resolved to cleared, FR-7.2a).
- The behaviour beyond the stated scale ceiling is undefined (feature.md NFR-5 / Q-6 / EC-14, trd.md TQ-3). The 50,000-record performance case asserts only what NFR-5 states; what should happen at a larger size — refuse, sample or stream — has no stated expectation.
- The page size of 50 rows is stated (FR-6.3) but flagged as possibly changing (feature.md Q-7, prd.md PQ-4), and trd.md TQ-6 additionally asks whether the client may supply a page size at all. No case exercises a client-supplied page size, and no case asserts a cap on it, because neither is settled.
- The 'Keeping' pill copy is not confirmed as verbatim-required (feature.md Q-8, prd.md PQ-3). The pill-state cases assert that a pill appears in the stated condition without asserting its exact wording.
- Whether the table gains an environments column is undecided (feature.md Q-4), pending the export capturing environment data. The column-structure case asserts the six columns currently specified.
- The scan mechanism is not confirmed (trd.md TC-1 / TQ-1). The API cases follow the async run-and-poll contract the TRD documents; if a synchronous findings request is chosen instead, the two run/poll endpoint cases no longer apply.
- FR-2.5 requires detecting 'asset URLs appearing in text fields' but no URL form is specified. The corresponding case states the requirement without a precise matching rule, so its pass condition depends on an implementation decision not present in the documents.
- FR-4.5 requires the table to be 'scrolled into view' with no measurable definition. The corresponding case cannot state a threshold and needs human confirmation in practice.
- FR-2.9 (excluding is_dir assets) has no data to exercise it: trd.md §18 records that no export this system produces contains asset folders. The two cases for it require a hand-made fixture rather than any real export.
- Whether the findings document carries a version, so a shape change invalidates old documents rather than being misparsed, is undecided (trd.md TQ-5). No case covers reading a findings document written by an earlier release.
- trd.md §18 records that feature.md §17's real-stack figures (366 / 55 / 77 / 134 / 132) predate two requirements and are wrong as stated; the correct figures are 241 / 8 / 70. No case uses §17's numbers — all quantitative cases use the F1/F2/F3 fixtures instead.
