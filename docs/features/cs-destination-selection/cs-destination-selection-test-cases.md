## Gaps / Needs Clarification

- **Stack-contents fetch failure fallback:** the exact UI fallback when fetching the destination stack's existing content statistics fails or times out (retry control, generic error message, silently showing the empty-state copy) is undecided (EC-14, Q-18). No test case is written for the failure path until the fallback behavior is defined.
- **Exact "Stack contents" metrics:** which stat tiles are shown for a non-empty stack (content types? entries? assets? how many tiles?) is undecided (Q-18). TC_DEST_048 tests that *some* stat tiles appear, not their specific content.
- **"Locales mapped" counting formula:** whether the mandatory master-locale row counts toward the Destination summary's "Locales mapped" total, and how, is undecided (Q-16). TC_DEST_045 tests that the summary updates live, not the exact number it should show.
- **Does an unset master-locale or branch destination choice block "Proceed"?:** neither is currently listed in the FR-6.1 gating condition, and the source documents call this out as unresolved (Q-17). The gating test cases here (TC_DEST_041–044) assume Region/Organization/Stack/import-authentication are the only gating fields, per FR-6.1's literal text — if Q-17 resolves to "yes, these also gate," those test cases will need new negative variants.
- **authToken's later-step sign-in:** what happens when no stored credential exists for the destination's region at the point authToken is actually used (prompting sign-in) happens in the Migrate step, which is explicitly out of scope for this feature (FR-3.7's note, feature.md §5). Only the storing/look-up-able side (TC_DEST_029) is tested here.
- **Destination summary's stack-related label:** the source documents note it still literally reads "New stack" even though existing-stack selection is now supported, and whether it should be updated (e.g. to "Stack") is undecided (Q-14). No test case asserts specific summary label copy for this.
- **Import-authentication field copy:** the "Management token name" field's hint text ("configured on the destination stack") reads as if referencing an existing token rather than creating one, and may need rewriting for clarity (Q-4). No test case asserts this specific hint copy.
- **Credential persistence:** whether the created management token's secret, or any looked-up Contentstack session credential, is persisted (encrypted) or kept request-scoped only is undecided (Q-5, Q-20). No test case asserts specific storage/retrieval behavior for these secrets.
- **Browser compatibility matrix:** the exact set of supported browsers is undecided (NFR-5, Q-10). No cross-browser test cases are included.
